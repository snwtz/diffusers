MULTISPECTRAL VAE TRAINING PIPELINE - DIGITAL ARCHIVE
====================================================

This digital archive contains the complete implementation of a multispectral VAE (MSAE) training pipeline
for adapting Stable Diffusion 3 (SD3) to generate synthetic 5-channel multispectral plant imagery.
The pipeline enables parameter-efficient fine-tuning of pretrained SD3 VAE for multispectral data
while maintaining spectral fidelity and SD3 compatibility. It builds on the HuggingFace diffusers 
repository (https://github.com/huggingface/diffusers). 

RESEARCH CONTEXT
---------------
This work addresses the challenge of adapting pretrained diffusion models for multispectral
plant imaging applications. The core innovation is a lightweight adapter architecture that
bridges 5-channel hyperspectral data to the 3-channel RGB format expected by SD3, enabling
synthetic multispectral image generation through DreamBooth fine-tuning.

CODE STRUCTURE
================
examples/multispectral/
├── vae_multispectral_dataloader.py
│   └── Multispectral image dataloader for MSAE training
│       - Handles 5-channel TIFF files
│       - Extracts specific bands (9, 18, 32, 42, 55) for plant analysis
│       - Implements background masking using NaN values
│       - Per-channel normalization to [-1, 1] range
│       - Supports train/val splits via file lists
│
├── multispectral_dataloader.py (DreamBooth dataloader)
│   └── Multispectral Image Dataloader for VAE/DreamBooth
│       - Shared preprocessing (band selection, NaN/mask handling, normalization)
│       - Returns dict batches (pixel_values, mask, prompts)
│       - Caching and deterministic options for tests vs GPU training
│
├── train_multispectral_vae_5ch.py
│   └── Main training script for MSAE adapter
│       - Multi-objective loss support
│       - Parameter-efficient fine-tuning (frozen RGB backbone)
│       - Monitoring and logging with Weights & Biases integration
│       - Early stopping and checkpointing
│
├── autoencoder_kl_multispectral_adapter.py
    └── MSAE adapter architecture
        - Lightweight adapters bridging 5→3→5 channels
        - Spectral attention mechanism for learned band importance
        - Frozen RGB backbone for parameter efficiency
        - Masked loss computation for leaf-focused training
        - SD3 pipeline compatibility
│
├── training_logger.py 
    └── Training monitoring and logging
        - Epoch-by-epoch training metrics 
        - Spectral band importance tracking and analysis
        - Output range statistics and compliance monitoring
        - Model health indicators 
        - Best model tracking and final training summary
        - Reconstructed mean spectrum monitoring with reference deviation
        - SSIM per-band performance metrics
│
├── eval_multispectral_vae.py
    └── MSAE evaluation and visualization
        - Multi-metric evaluation (MSE, SAM, SSIM) with foreground/background separation
        - Pseudo-RGB visualization for human eye interpretation
        - Spectral signature analysis and error mapping
        - Per-band performance analysis and aggregated metrics
        - Reference signature comparison and deviation tracking

│
├── split_dataset.py
    └── Dataset preparation and train/val splitting
        - Validates multispectral TIFF files for VAE training requirements
        - Implements 80/20 train/validation split with fixed random seed
        - Filters files based on naming patterns (healthy, non-stressed leaves)
        - Creates train_files.txt and val_files.txt for training pipeline
        - Documents splitting methodology and data quality criteria
│
└── Get_SD3_VAE.py
    └── SD3 VAE extraction utility
        - Downloads and extracts VAE component from default RGB SD3 pipeline
        - Saves VAE weights and configuration for adapter training
        - Provides base VAE backbone for multispectral adapter architecture

Benchmark:
- src/diffusers/models/autoencoders/autoencoder_ms_benchmark.py

examples/dreambooth/

│   └── DreamBooth fine-tuning with multispectral support

│       - Loss with configurable weighting schemes

│       - Spectral monitoring: per-band MSE/SSIM, global SAM, output range
│       - Validation image logging and optional Weights & Biases integration
│
├── inference_dreambooth_multispectral.py
│   └── CLI inference for DreamBooth multispectral models
│       - Loads saved transformer, VAE, text encoders, tokenizers, scheduler
│       - Manual pipeline construction for SD3 with multispectral VAE
│       - Pseudo-RGB conversion and saving of individual band plots
│       - Optional saving of raw 5‑channel outputs for analysis
│       - Deterministic generation via seed control
│
└── dreambooth_logger.py
    └── Training logger for DreamBooth multispectral runs
        - Step/epoch logging to compact text files
        - Periodic spectral summaries (SAM, per‑band MSE/SSIM)
        - Range monitoring for decoded outputs (per‑band + overall)
        - Validation image saving
        - Optional logging to Weights & Biases


CONFIGURATION AND SETUP
-------------------------

The pipeline requires:
- Python 3.8+ with PyTorch, diffusers, rasterio
- CUDA-compatible GPU for training
- Hyperspectral TIFF files with at least 55 bands
- Weights & Biases account for experiment tracking (optional)

LOGGING AND MONITORING
-------------------------

- Training/validation loss (total, per-channel MSE, global SAM)
- Learning rate and gradient norm
- Per-band MSE and SSIM (5 spectral bands)
- Spectral signature comparison with reference
- Scale convergence monitoring
- Output range statistics
- Model health (memory usage, NaN detection)
- Band importance weights (spectral attention)

USAGE WORKFLOW
-----------------

1. Data Preparation:
   - Organize hyperspectral TIFF files
   - Create train/val split files using split_dataset.py
   - Ensure files contain required bands (9, 18, 32, 42, 55)

2. VAE Training:
   - Run train_multispectral_vae_5ch.py with appropriate arguments
   - Monitor training via Weights & Biases dashboard
   - Check output range statistics and scale convergence
   - Save best model checkpoint

3. DreamBooth Integration:
   - Use trained VAE in SD3 + DreamBooth pipeline
   - Generate synthetic multispectral images
   - Evaluate spectral fidelity and plant health analysis
